# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-09-27

## Context

We want the reasoning behind important choices to be discoverable by humans and AI agents.

## Decision

Keep Markdown ADRs in `docs/adr/`, numbered sequentially, using `0000-template.md`. The PR that
implements a significant decision includes its ADR.

## Consequences

Small overhead per decision. Much less re-litigating of settled choices.
